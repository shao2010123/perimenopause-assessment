# v5.5 指令文件

## 核心展示原则

从 v5.0 起，报告面向用户的可见区域不展示四模式原始后验数值，不展示四模式并列图表，也不使用“匹配度”“符合概率”等措辞。内部算法仍保留四模式计算、BMI 与年龄交互、甲状腺和胰岛素风险评分、复合模式判断；展示层只呈现阶段、症状严重度、1-2 个主导变化线索和行动建议。

用户阅读优先级：

- 你处于哪个阶段：STRAW+10 分期。
- 你的症状有多重：症状与代谢负担严重程度分级。
- 你的身体可能正在经历什么：主导激素变化线索或变化初期解释。
- 你可以怎么做下一步：日常管理与了解更多。
- 这个评估怎么做：方法论说明、免责声明和参考文献，默认折叠。

## 问卷结构保留

v4.0 的问卷结构继续生效：

- Q2 保留 A-I 九选项，用于月经状态和特殊无月经情况分流。
- Q2=A/B/C 时显示 Q8-Q11 月经相关细化题；Q2=D/E/F/G/H/I 时跳过经量、经前和周期变化题，仅保留异常出血红旗筛查。
- Q8（月经量变化）必须覆盖：没什么变化、明显变少、有时多有时少、明显变多、过多影响生活。明显变少不得按“经量增多”计权，应作为卵巢功能变化/雌激素下降相关线索处理。
- Q10 保留 A-E 五选项，仅当 Q2=A/B/C 时显示。
- Q5 保留医疗与手术史七选项：单侧卵巢切除、甲状腺手术、化疗/放疗、PCOS、甲状腺功能异常、POI、以上都没有。
- Q5 与 Q2 继续做交叉校验：Q2=H 优先于单侧卵巢切除；甲状腺手术和甲状腺异常合并为一个甲状腺病史标记；POI 会保留特殊提示。

## STRAW+10 分期

报告第一屏输出“你的阶段判断”。普通自然过渡阶段显示五节点时间轴：

- 育龄晚期 -3
- 早期过渡 -2
- 晚期过渡 -1
- 早期绝经后 +1
- 晚期绝经后 +2

时间轴下方只显示一句依据说明，长度控制在 50 字左右。阶段旁使用文字标签：“可能”“较可能”“很可能”“高度可能”。

特殊情况不显示普通时间轴：

- Q2=F：说明曼月乐会影响月经判断，建议结合 FSH 和 E2。
- Q2=G：说明子宫切除后缺少月经参照，建议 FSH、E2、AMH。
- Q2=H：说明双侧卵巢切除后属于手术性绝经。
- Q2=I：说明月经缺失原因复杂，建议医生结合激素检测判断。

## 症状严重程度

报告第二屏输出“你的症状负担”，从 v5.4 起采用自适应展示策略：

- 轻症汇总模式：当综合症状负担为“无/轻微”或“轻度”，且没有任何单一维度达到“中度”或以上时，不展示五行条形图，改为居中的整体分级标签和 1-3 句温和解读文字。
- 分维度展示模式：当综合症状负担为“中度”或“重度”，或至少一个维度达到“中度”或以上时，展示五维度紧凑条形图。

五维度定义不变：

- 血管舒缩症状：潮热、盗汗。
- 情绪与认知：压力耐受、焦虑、低落、注意力/记忆。
- 泌尿生殖：阴道干涩、性生活变化、泌尿生殖相关线索。
- 躯体症状：睡眠、关节/肌肉、疲劳恢复、心率/心悸线索。
- 代谢与胰岛素敏感性：餐后犯困、甜食渴望、饥饿反应、腰腹增重。

分级规则：

- 无/轻微：ratio ≤ 0.15。
- 轻度：0.15 < ratio ≤ 0.35。
- 中度：0.35 < ratio ≤ 0.60。
- 重度：ratio > 0.60。

轻症汇总模式下不展示进度条、单维度标签或综合汇总行。如果所有维度得分为 0，文案提示“目前没有报告明显症状”；如果有少量轻微感受，最多提及 2 个相关维度。

分维度展示模式下使用缩短名称：潮热盗汗、情绪认知、泌尿生殖、躯体症状、代谢。默认视图仅展示维度名称、进度条和分级标签，不展示原始分数、分母、维度说明文字或方法论副标题。无/轻微维度用浅灰弱化，中度/重度维度用加粗文字和彩色进度条突出。点击任意维度行可展开查看原始分数和说明。综合分为 68 分制，默认只展示综合分级；总分 ≥14 时提示“你的症状可能已影响生活质量，建议与医生讨论是否需要干预”。报告不展示小数、百分比转换或人群排名。

## 激素变化线索展示

内部四模式计算保留，但展示层做转换：

- top1 ≥0.55：展示一个主导线索，标记为“高度吻合”，星级 ★★★。
- 0.35≤ top1 <0.55：展示一个主导线索，标记为“中度吻合”，星级 ★★☆。
- top1 - top2 <0.10 且 top2 ≥0.20：最多展示两个线索，均使用描述性标签。
- top1 <0.35：不展示任何模式标签，不使用“不属于”“无法归类”“不匹配”等措辞；改用“变化初期”叙事框架，解释激素变化刚开始、感受轻微而分散是常见状态。
- 小于 0.20 的模式永远不展示给用户。

v5.0 展示名：

- A：孕激素减退型。
- B：激素波动失衡型。
- C：激素剧烈波动型。
- D：雌激素显著减退型。

## 报告页面结构

报告采用单页长滚动，主流程控制在移动端约四屏：

- 第一屏：你的阶段判断，STRAW+10 时间轴或特殊情况说明卡片。
- 第二屏：你的症状负担，按 v5.4 自适应显示轻症汇总或五维度条形图。
- 第三屏：你的身体正在经历什么，叙事段落、星级线索或变化初期提示，以及“了解你的变化/现在可以做什么”卡片。
- 第四屏：建议与下一步，最多四张行动卡片。
- 页脚：关于本评估、科学依据、免责声明与报告操作，默认折叠。

## 身体变化解释

从 v5.5 起，第三屏永久移除“身体变化解读”pill tag，避免与标题重复。

有明确主导模式时，叙事逻辑保持不变：展示主导线索、星级和简短机制解释；下方卡片标题为“了解你的变化”。

当 top1 <0.35 时，不再提示“症状组合暂不属于单一典型模式”，也不说“你目前的症状组合不属于任何单一典型模式”。这一分支按阶段和症状负担分流：

- 如果处于生育晚期/围绝经早期，且综合症状负担未达到中度、没有任何中度以上维度，使用“变化初期”框架。
- 如果已经是围绝经晚期、绝经后，或综合症状负担/任一维度达到中度以上，使用“多线索变化 · 过渡期信号”框架，不再说“早期”。

变化初期框架：

- 标签显示“变化初期 · 早期信号”。
- 正文说明身体变化还处于比较早期的阶段，卵巢功能可能已经悄悄调整，但症状仍轻微、分散。
- 根据 STRAW 阶段动态调整措辞：生育晚期强调 AMH、抑制素B、黄体期孕酮的早期变化；围绝经早期强调周期变化和激素分泌调整。
- 根据用户实际报告的症状最多补充 1 句。
- 若有甲状腺相关病史，只解释甲状腺感受与围绝经期感受容易重叠，不在叙事段落里重复检查建议。
- 下方卡片标题为“现在可以做什么”，内容可提示建立激素基线；具体检查项目仍由第四屏“了解更多”卡片承载。

多线索过渡期框架：

- 标签显示“多线索变化 · 过渡期信号”。
- 正文说明虽然没有单一模式特别突出，但月经阶段和高分维度已提示身体处于明确过渡期。
- 优先点出中度/重度维度，例如泌尿生殖、代谢等。
- 下方卡片标题为“了解你的变化”。

第三屏叙事段落只负责解释身体变化，不重复检查组套、检查时机或“具体检查以上方组套为准”等内容。

## 检查推荐组套

从 v5.1 起，报告中“可以通过什么检查确认”不再把 FSH、E2、LH、P、T、PRL 拆成独立检查项。中国大陆临床实际开单多以“性激素六项”组套执行，拆开罗列会让用户到医院后难以对应。

从 v5.3 起，检查推荐不再作为第三屏的独立模块展示，统一迁入第四屏“建议与下一步”的“了解更多”类卡片，避免同一组套在报告前后重复出现。

检查推荐按以下组套输出：

- 性激素六项：包含 FSH、LH、E2、孕酮、睾酮、泌乳素。除 Q2=H 双侧卵巢切除外，作为基础推荐。Q2=A/B 时建议月经第 2-5 天空腹抽血；Q2=C 或已闭经/周期不可用时，可随时抽血作为基础水平参考。
- AMH（抗缪勒管激素）：除 Q2=H 外均推荐。用于评估卵巢储备，不受月经周期影响，任何时间都可以查。
- 甲状腺功能五项：甲状腺筛查触发、甲状腺风险较高，但没有明确甲状腺手术/疾病史时推荐。包含 TSH、FT3、FT4、TT3、TT4，更贴近国内医院常见“甲功五项”组套。
- 甲状腺功能七项：Q5 选择甲状腺手术/甲状腺功能异常时推荐。包含 TSH、FT3、FT4、TT3、TT4、TPOAb、TGAb，用于同步查看甲状腺自身免疫相关线索。
- 代谢相关检查：胰岛素抵抗风险偏高时推荐，包含空腹血糖、空腹胰岛素；风险更高时增加糖化血红蛋白（HbA1c）。
- 骨密度检查（DXA）：晚期过渡、绝经后、手术性绝经或年龄≥50 时推荐。

Q2=H 时，不推荐性激素六项和 AMH，改为提示“双侧卵巢已切除，相关检查诊断意义有限，建议直接与医生讨论绝经后健康管理方案”。

## 行动建议模块

从 v5.3 起，行动建议不再按“紧迫度”分层，也不使用“建议尽快检查”、红色警示编码或“颜色表示紧迫程度”等文案。问卷不是急诊分诊工具，行动模块应保持温和、可执行、非恐吓。

第四屏标题固定为“建议与下一步”，不显示“建议关注”标签，不显示副标题。卡片最多展示四张，分为两类：

- 日常管理：绿色左侧边线 #66BB6A，用于运动、饮食、睡眠、压力管理、私密健康、关节肌肉等自我管理建议。语气使用“可以试试”“日常中可以关注”“很多女性发现……有用”，避免“必须”“应该”“禁止”。
- 了解更多：蓝色左侧边线 #5B8DEF，用于性激素六项、AMH、甲状腺功能、代谢相关检查、骨密度检查，以及下次就诊时可与医生讨论的话题。语气使用“建议在方便时检查”“下次就诊时可以和医生聊聊”“有助于更清楚地了解”，避免“需要立即”“务必”“警惕”“不容忽视”。

卡片选取规则：

- 先根据问卷结果生成所有可用卡片。
- “了解更多”最多选两张，优先承接检查组套内容。
- 剩余位置由“日常管理”补足。
- 最终排序为“日常管理”在前，“了解更多”在后。
- 每张卡片包含类型标签、标题、解释正文和“下一步”行动列表。

页面中永久移除：

- 四模式环形图、饼图或并列数值对比。
- 可见区域的原始四模式数值。
- 中部隐私声明和过长逐项症状罗列。
- 特殊情况的重复提示；不确定性只在第一屏说明一次。
