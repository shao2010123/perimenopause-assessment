# 围绝经期综合健康筛查测评设计说明

## 目标

构建一个纯前端单页应用，用 30 道围绝经期相关问题完成本地测评、概率推断、风险提示、推荐检测和 PDF 报告导出。全部数据仅保存在浏览器本地，不接入后端。

## 结构

- 首页：介绍用途、时长、本地存储承诺，并提供开始测评与查看上次报告入口。
- 问卷：按 3 个主题分页，支持上一步、进度回跳、必填校验、实时红旗提示。
- 结果页：展示激素模式概率、叠加风险、红旗、推荐检测、生活方式建议、免责声明与 PDF 导出。

## 实现原则

- React 18 + Vite 负责渲染和构建。
- Tailwind CSS 4 负责视觉系统，采用暖米白底、薰衣草紫主色和圆角卡片风格。
- 推断引擎与推荐逻辑全部运行在浏览器端。
- localStorage 保存上次答案与结果。
- 使用 Recharts 绘制水平条形图与半圆风险图。
- 使用 html2pdf.js 导出结果页为 PDF。

## 关键逻辑

- 第 2 页对 `Q2 === 'E'` 用户仅展示 `Q9`，并改写题干为绝经后出血版本。
- 红旗规则支持当前页实时提醒和结果页汇总。
- 模式概率使用标准题权重、先验加分和特征加分综合计算，再归一化为百分比。
- 甲状腺风险拆分为总体风险和方向判断，避免把泛症状全部等价为甲状腺异常。

## 测试重点

- 3 个给定样例的主模式、风险区间和推荐结果。
- 生产构建输出到 `dist/`，并启用 `base: './'`。
